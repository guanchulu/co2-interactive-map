# Public Repository Notes

This public repository contains the CO2 allocation model code, lightweight public input interfaces, manuscript figures, and the static interactive map.

Large raw downloads and generated model output tables are intentionally excluded from git:

- `data/raw/`
- `output/`
- `data/real_inputs*/`
- non-redistributable CEADs expansion tables
- Office temporary lock files and ZIP review bundles

The GitHub Pages root redirects to `docs/interactive_map_public/static_site/`.
